# @artil/utils

Small helpers with no dependencies, shared across the workspace.

## Usage

| Import               | What it gives                                                           |
| -------------------- | ----------------------------------------------------------------------- |
| `@artil/utils/shell` | `shellQuoted`, to print a command a person can paste                    |
| `@artil/utils/text`  | `formatBytes`                                                           |
| `@artil/utils/time`  | `second`, `minute`, `hour`, `day` in milliseconds, and `abortableSleep` |
