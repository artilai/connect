# @artil/telegram-channel

The Telegram channel: a bot that takes messages through the Bot API, by webhook
or by asking for updates, and sends them back.

## Usage

| Import                    | What it gives                           |
| ------------------------- | --------------------------------------- |
| `@artil/telegram-channel` | `channel`, the channel the server loads |

A bot connects with its token: open @BotFather in Telegram, send `/newbot` to
make a bot or `/mybots` to pick one you have, tap API Token and copy it. People
then write to the bot first, in a private chat or by tagging it in a group it
is in, and the agent answers them.
